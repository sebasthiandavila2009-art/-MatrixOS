# MatrixOS

**MatrixOS** is an independent operating system and technology ecosystem developed by **MatrixOS Co.**

## Vision

MatrixOS is being built to provide a modern, independent software platform designed for future devices, including smartphones and other connected hardware.

## MatrixOS Base

The initial development focuses on building the core operating system:

- Bootloader
- Kernel
- Hardware drivers
- Filesystem
- System services
- User interface
- Applications

## Development Status

**Version:** 0.1  
**Status:** Early Development

The first milestone is to successfully boot MatrixOS and display:

> MATRIXOS v0.1
